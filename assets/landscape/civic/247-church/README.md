# Church (247)

Four original Imagegen paintings from fixed quarter-turn layout guides. Master tile width is 128 pixels.
The baked 2×2 foundation uses the exact native terrain mask, with painted ground and shadows retained.
Bake with `python3 tools/bake_civic_sprites.py assets/landscape/civic/247-church`.
See `bake-result.json` for edge checks and `final-rotations-preview.png` for the baked views.
Fine painted details can vary between angles.

Nave entrance faces v-max visible0/3, hidden1/2. Bell tower frontleft. Transept u-axis. One copper spire, fixed asymmetric church plan. Accepted firstpainting rear polygonal apse included in guide.
