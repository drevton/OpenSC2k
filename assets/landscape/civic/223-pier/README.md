# Pier (223)

Four genuine quarter-turn views from one fixed Blender layout, finished with the built-in Imagegen tool. Source water paintings, registered foreground extractions, prompts, model and guides are retained.

Bake with `python3 tools/bake_civic_sprites.py assets/landscape/civic/223-pier`.
Final sprites contain only the structure; native terrain and animated water show beneath.
`omit_ground_in_sprite` keeps `ground-N.png` for exact native mask validation without compositing it.
All views have zero mask mismatch, sprite overflow and opaque trimming.
