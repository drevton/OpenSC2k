# Rail Station (237)

Four original Imagegen paintings from fixed quarter-turn layout guides. Master tile width is 128 pixels.
The baked 2×2 foundation uses the exact native terrain mask; painted paving, planting and shadows remain inside it.
Bake with `python3 tools/bake_civic_sprites.py assets/landscape/civic/237-rail-station`.
Inspect `bake-result.json` and `final-rotations-preview.png`.
Fine painted details can vary between views.
