# Blender vehicle sources

Original procedural models and materials generated by
`tools/render_road_vehicles_blender.py`. No third-party vehicle assets are used.
See the parent README for the camera, ground registration, palette bake and
runtime integration. `vehicles.blend` opens with the hatchback visible; the other
six model roots retain their child meshes for editing and rendering.

The registered `car-000.png` through `car-167.png` are 4× supersampled inputs.
`manifest.json` freezes their order and SHA-256 hashes. Regenerate the complete
flat family before baking; custom `--model`, `--heading` or `--pitch` studies
write to a separate output directory and do not replace the game sources.

Use `--review` for 960×600 blue-paint front, side and rear views. Review renders
write separately to `/tmp/sc2k-road-vehicle-review`. Assemble the checked-in
`review.png` with the parent README's bake command after reviewing all models.
