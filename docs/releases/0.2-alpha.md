# OpenSC2k 0.2 Alpha

OpenSC2k is an open-source SimCity 2000 clone with 4× resolution, 32-bit graphics.
It includes its own graphics, music and sound effects and requires no original game installation.

## Changes

- Native `.sc2k` saves now use one RIFF stream compressed in one Zstandard frame, with
  checksummed records, streaming city summaries and terrain previews, and writer version metadata.
- Imported highway bridges retain both lanes and connect to their bank approaches.
  Dry terrain beneath highways is preserved, and bridge drawing uses the correct deck elevation.
- Imported emergency dispatch markers are restored only when they are linked to a map tile,
  preventing stray fire trucks and other stale markers.
- Map painting reads City state without copying the complete City record. Painting randomness and
  animation capture state belong to Drawing; sparse water-source sorting uses integer keys directly.
- Terrain generation, tile-family operations, save codecs, audio playback and UI presentation
  have clearer module boundaries and more explicit data ownership.

- Tool labels live with the UI definitions as borrowed strings, removing the copied Assets name table.
- Subway-to-Rail Connection, Woodland Arcology and Spaceport Arcology use consistent labels
  in the interface and building descriptions.

## Save compatibility

Original SimCity 2000 `.SC2` import/export remains supported. This release uses native save-format
version 4. Earlier experimental native formats are unsupported; retain the original `.SC2` files
and keep backups before replacing saved cities.

## Downloads

The macOS build supports Apple Silicon and Intel Macs running macOS 12 or newer.
The Windows build supports 64-bit Windows. Release asset packs use Zstandard level 15.
